# ◆ Nexovia

**Turn every camera into a thinking eye.**

Nexovia is an AI-powered edge device (the **Nexovia Hive**) that converts any standard IP camera into an intelligent, analytical camera — no rip-and-replace required.

## What It Does

The Hive sits between your existing cameras and your network. It ingests RTSP/ONVIF streams, runs real-time AI inference on-device, and outputs actionable alerts — all in under 50ms.

- 🔫 **Weapon Detection** — Identifies firearms and triggers lockdown protocols
- 🚗 **Hit & Run Tracking** — Stitches cross-camera footage into a continuous pursuit timeline
- ⚠️ **Accident & Spill Detection** — Auto-dispatches EMS with location and severity data
- 👤 **Intrusion Alerts** — Behavioral analysis to flag unauthorized presence
- 📹 **Seamless Camera Handoff** — Unified tracking across your entire camera network

## How It Works

```
IP Cameras → Network Switch → Nexovia Hive → Router → Your Devices
```

1. **Connect** — Plug the Hive into your network. It auto-discovers all camera streams.
2. **Configure** — Select detection models per camera via the dashboard.
3. **Detect** — AI inference runs on-device. Alerts route to your phone, control room, or API.

Setup takes ~10 minutes. Zero cameras replaced.
